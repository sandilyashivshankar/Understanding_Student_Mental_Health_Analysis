## 🔎 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a student mental-health survey dataset.

The analysis uses Python-based data analysis and visualization techniques to explore relationships among academic experiences, financial concerns, social relationships, and self-reported mental-health indicators.

The goal is to transform a raw survey dataset into **clear, interpretable analytical insights** through data cleaning, exploration, visualization, and structured interpretation.

> **Important:** This project is an exploratory data-analysis exercise. It does not diagnose mental-health conditions and should not be interpreted as clinical or medical advice.

---

## 🎯 Objectives

- Understand the structure and quality of the survey dataset.
- Clean and prepare the data for analysis.
- Explore important demographic and academic variables.
- Analyze relationships between academic pressure and other survey factors.
- Explore financial and social factors represented in the dataset.
- Visualize patterns in self-reported depression, anxiety, isolation, and future insecurity variables.
- Practice turning raw survey data into meaningful analytical observations.

| 🤝 Social Factors | `social_relationships`, `isolation` |
| 🧠 Self-Reported Indicators | `depression`, `anxiety`, `future_insecurity` |
| 🧘 Activities | `stress_relief_activities` |

The exact variables and values should be interpreted from the source dataset and notebook analysis.

## 🚀 Run the Project Locally

### 1. Clone the repository


### 2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyterlab
```

### 3. Launch Jupyter

```bash
jupyter lab
```

### 4. Open the notebook

Open:

```text

```

Run the notebook cells sequentially to reproduce the analysis.
